The <info>%command.name%</info> command generates a new Twig extension class, with
a filter and a function declared through the <comment>#[AsTwigFilter]</comment> and
<comment>#[AsTwigFunction]</comment> attributes.

<info>php %command.full_name% AppExtension</info>

If the argument is missing, the command will ask for the class name interactively.
